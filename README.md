# english boost

pet-проект для удобного изучения иностранных языков.

- возможность формирования собственного словаря из загружаемых текстов
- режим чтения: подсветка слов по стадии изучения, перевод по клику
- изучение не только слов, но и устойчивых выражений
- повторение изученных слов по интервальной системе
- порядок изучения определяется частотностью слова
- английский и сербский, словари не смешиваются между языками

# запуск

Нужен Node `^20.19.0 || >=22.12.0` (версия зафиксирована в `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

# перевод

Переводит локальная модель через OpenAI-совместимый API — по умолчанию
`translategemma-12b-it` в [LM Studio](https://lmstudio.ai/) на `http://127.0.0.1:1234`.

Запросы из браузера идут на относительный путь `/llm`, который dev-сервер vite
проксирует на модель. Браузер видит запрос как свой собственный origin, поэтому
включать CORS в LM Studio не нужно.

Переопределяется через переменные окружения:

| переменная | по умолчанию | назначение |
|---|---|---|
| `VITE_TRANSLATOR_TARGET` | `http://127.0.0.1:1234` | куда vite проксирует `/llm` |
| `VITE_TRANSLATOR_MODEL` | `translategemma-12b-it` | имя модели в запросе |
| `VITE_TRANSLATOR_URL` | `/llm/v1/chat/completions` | полный адрес, если прокси не используется |

При статическом деплое без прокси задайте `VITE_TRANSLATOR_URL` абсолютным
адресом и включите CORS в настройках сервера LM Studio.

Первый запрос после старта LM Studio грузит модель в память — это занимает
минуты, поэтому таймаут прокси поднят до 15 минут.

# Советы

Изучение английского языка состоит из развития четырех основных навыков (Чтение, Аудирование, Письмо, Говорение) и двух фундаментальных блоков (Словарный запас и Грамматика).Чтобы занятия были эффективными, упражнения разделяют на две категории:Пассивные (Input): потребление информации (чтение, слушание, разбор грамматики и слов).Активные (Output): производство языка (говорение, письмо, составление собственных предложений).Основные виды упражненийВосприятие на слух (Listening)Прослушивание подкастов, аудиоблоков или видео с разбором (для своего уровня).Упражнения типа Listen and Fill in the Blanks (заполнение пропусков на слух).Теневое повторение (Shadowing) — повторение фразы за диктором стык в стык для отработки интонации и произношения.Чтение (Reading)Чтение адаптивных или оригинальных текстов/статей.Чтение вслух (для связи зрительного и слухового восприятия).Разбор незнакомых конструкций и контекстный перевод.Словарный запас и Грамматика (Vocabulary &
